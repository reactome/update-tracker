This is the project that is used to analyze changes between two slices (releases). The project should be run after slicing. In the graph database context, to run this, you may have to set some environment variables first. On how to set this up, take a look at README.md at slice-tool: https://github.com/reactome/slicing-tool. 

**Note**

Make sure the user name and the account for the h2 database should be the same.
